# แนวฝึกจากคาบทบทวน ITDS211

เพิ่ม 72 ข้อ บทละ 9 ข้อ โดยแต่ละบทมีง่าย/กลาง/ยากอย่างละ 3 ข้อ คลังเดิม 252 ข้อคงอยู่ รวมเป็น 324 ข้อ ตัวเลือกและเลขข้อยังสลับตามระบบเดิม คำตอบเก่ายังอ้างด้วยรหัสโจทย์เดิม

## ขอบเขตแหล่งข้อมูล

- เสียงที่ผู้ใช้ให้วันที่ 25 ตุลาคม 2026 ยาวประมาณ 2:34:10 ถอดตลอดไฟล์ในเครื่องด้วย [faster-whisper](https://github.com/SYSTRAN/faster-whisper) เพื่อค้นหาช่วงถาม–ตอบ ไม่มีการอัปโหลดเสียงไปบริการถอดเสียง
- สไลด์ ITDS211 บท 1–8 ที่ผู้ใช้ให้ก่อนหน้านี้ รวม 510 หน้า บท 6–8 ที่ส่งมาอีกครั้งมี hash ตรงกับสำเนาเดิม
- ตัวอ่านแชต Lecturer ส่งข้อความผู้ใช้และไฟล์อ้างอิงมาได้ แต่ข้อความตอบผู้ช่วยปรากฏเป็น content reference จึงไม่ใช้เป็นหลักฐานว่าได้อ่านบทถอดเสียงจากแชตนั้น
- ASR มีคำเทคนิคคลาดเคลื่อนและบางช่วงซ้ำผิดธรรมชาติ ใช้เฉพาะช่วงที่จับประเด็นได้และตรวจหลักกับสไลด์ ไม่อ้างว่าโจทย์เป็นคำพูดตรงทุกคำ ไม่ใช้ช่วงคลุมเครือมายืนยันกติกาหรือเนื้อหาข้อสอบจริง

`audio-adapted` คือปรับประเด็นถามหรือการอภิปรายที่อ่านได้จากเสียงให้เป็น 4 ตัวเลือก บางประเด็นมาจากผู้เรียนถามแล้วอาจารย์อธิบาย จึงไม่ระบุผู้พูดแบบคำต่อคำ ส่วน `style-transfer` คือโจทย์ใหม่ที่ใช้รูปแบบถามเดียวกัน เช่น เปลี่ยนตัวเลข กลับทิศการคำนวณ วิเคราะห์ข้อผิดพลาด หรือใช้หลักเดียวกันกับสถานการณ์อื่น

ทุกข้อมี `provenance` ระบุชนิด รูปแบบ ช่วงเวลาเสียง และประเด็นต้นแบบ พร้อม `from/to` เป็นหน้า PDF ของหลักที่ใช้ตอบ คำอธิบายที่มาแสดงหลังลองตอบแล้วเท่านั้น ไม่เฉลยเพิ่มบนหน้าคำถาม

## การเก็บข้อมูลและตรวจสอบ

ไฟล์เสียง วิดีโอ บทถอดเสียงดิบ และเครื่องมือ ASR อยู่เฉพาะเครื่องหรือโฟลเดอร์ `.cache/` ที่ Git ignore เผยแพร่เฉพาะโจทย์ที่เรียบเรียงใหม่และข้อมูลอ้างอิง ระบบเว็บไม่มีบริการรับเสียงหรือหลังบ้านเพิ่ม

ตรวจด้วย `tests/lecture-practice.test.cjs` และ `tests/lecture-ui.test.cjs`: จำนวน/ชนิดโจทย์ ช่วงหน้าและเวลา ตัวเลือก รหัสเดิมไม่ถูกทับ การเปิดที่มาหลังตอบ การฝึกทีละข้อ และการเปิดบันทึกข้อสอบรุ่นก่อนที่มีคำถามน้อยกว่า รันร่วมกับชุดเดิมผ่าน `node tools/check.cjs`
