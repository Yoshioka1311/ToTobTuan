CSS คืออะไร CSS Syntax การระบุสี

Cascading Style Sheets (CSS) คืออะไร

นิยาม

Cascading Style Sheets (CSS) ถูกสร้างขึ้นเพื่ออธิบายว่า HTML element แต่ละตัวควรแสดงผลอย่างไรบนหน้าจอ บนกระดาษ หรือบนสื่ออื่นๆ

แนวคิดสำคัญของ CSS คือการแยกการจัดรูปแบบ (style) ออกจาก HTML tag — HTML ทำหน้าที่บอกโครงสร้างและความหมายของเนื้อหา ส่วน CSS ทำหน้าที่บอกหน้าตา เมื่อแยกกันแล้วการจัดการสไตล์ของทั้งเว็บจะง่ายขึ้นมาก

ทำไมการแยก style ออกมาจึงช่วยได้มาก

เมื่อเก็บสไตล์ไว้ใน external style sheet (ไฟล์ .css แยก) หลายหน้า HTML ใช้ไฟล์เดียวกันได้ จึงประหยัดความพยายามได้มาก — แก้ที่ไฟล์เดียวแล้วมีผลกับทุกหน้าที่เชื่อมไฟล์นั้นอยู่ (รายละเอียดอยู่ในการ์ด 03)

โครงสร้างไวยากรณ์ CSS (CSS Syntax)

กฎ CSS หนึ่งกฎ (rule) ประกอบด้วย selector ที่บอกว่าจะจัดสไตล์ element ไหน ตามด้วย declaration block ที่บอกว่าจะจัดสไตล์อย่างไร ตัวอย่างจากสไลด์:

body {
    background-color: red;
    font-family: Arial;
}
ส่วนประกอบในตัวอย่างความหมาย
Selectorbodyชี้ไปยัง HTML element ที่ต้องการจัดสไตล์
Declarationbackground-color: red;ชื่อ CSS property กับค่า (value) คั่นด้วย colon (:) และจบด้วย semicolon (;)
Declaration block{ ... }กลุ่มของ declaration ที่ครอบด้วยวงเล็บปีกกา
Comment/* ... */คำอธิบายในโค้ด browser จะไม่แสดงผล
ข้อควรระวัง

property กับค่าคั่นด้วย : (ไม่ใช่ = แบบ attribute ใน HTML) และแต่ละ declaration ปิดท้ายด้วย ; — ส่วน comment ใน CSS ใช้ /* ... */ ไม่ใช่ <!-- --> แบบ HTML

การระบุสีใน HTML/CSS

สีระบุได้ 2 แบบ

รหัสเลขฐานสิบหก RGB hexadecimal

เขียนขึ้นต้นด้วย # เช่น #FF0000 = red

ชื่อสี color name

ใช้ชื่อสีได้โดยตรง เช่น red, orange, gold

<style>
  /* สีเดียวกัน เขียนได้ 2 แบบ */
  .hex  { color: #FF0000; }
  .name { color: red; }
  .gold { background-color: gold; }
</style>
<p class="hex">สีจากรหัส #FF0000</p>
<p class="name">สีจากชื่อ red</p>
<p class="gold">พื้นหลังสี gold</p>

Universal Element Class ID Grouping Descendant Pseudo-class ลองเล่น selector Specificity

selector คือหัวใจของ CSS เพราะเป็นตัวบอกว่ากฎนั้นมีผลกับ element ไหน บทนี้เรียน selector หลัก 7 แบบต่อไปนี้

1. Universal selector *

เครื่องหมาย * เลือกทุก element ในหน้า ใช้เมื่อต้องการให้ทุก element ใช้ style ร่วมกัน ตัวอย่างนี้ทำให้ข้อความทุก element จัดกึ่งกลางและเป็นสี coral

<style>
  * { text-align: center; color: coral; }
</style>
<h1>Heading</h1>
<p>Paragraph</p>
<span>Span</span>

2. Element selector

ใช้ชื่อ HTML tag เป็น selector โดยตรง เช่น p { color: coral; } จะมีผลกับ <p> ทุกตัวในหน้า แต่ไม่มีผลกับ tag อื่น

<style>
  p { color: coral; }
</style>
<h2>h2 ไม่เปลี่ยนสี</h2>
<p>p ตัวที่ 1 เป็นสี coral</p>
<p>p ตัวที่ 2 ก็เป็นสี coral</p>

3. Class selector .ชื่อclass

ใช้ attribute class ของ tag เป็น selector โดยเขียนนำหน้าด้วยจุด (.) เช่น .clsSp { ... } จะมีผลกับทุก element ที่มี class="clsSp" ไม่ว่าจะเป็น tag อะไร

  • เจาะจงร่วมกับชื่อ tag ได้: p.clsSp { ... } มีผลเฉพาะ <p> ที่มี class="clsSp" เท่านั้น — tag อื่นที่มี class เดียวกัน (เช่น <span class="clsSp">) จะไม่ได้รับผล
  • element หนึ่งตัวใส่หลาย class ได้ โดยเว้นวรรคคั่น เช่น <p class="line red"> ซึ่งจะได้รับสไตล์ทั้งจาก .line และ .red
<style>
  .clsSp  { background-color: gold; }
  p.clsSp { color: blue; }
  .line   { border-bottom: 2px solid gray; }
  .red    { color: red; }
</style>
<p class="clsSp">p class="clsSp" — พื้น gold และตัวอักษรสีน้ำเงิน</p>
<span class="clsSp">span class="clsSp" — พื้น gold แต่ไม่เป็นสีน้ำเงิน</span>
<p class="line red">p class="line red" — ได้ทั้งเส้นใต้และสีแดง</p>

4. ID selector #ชื่อid

ใช้ attribute id เป็น selector โดยเขียนนำหน้าด้วย hash (#) เช่น #p1 { ... } จะมีผลเฉพาะ element ที่มี id="p1"

ข้อควรจำ

ค่า id ต้องไม่ซ้ำกันในหน้า — ID selector จึงชี้ element ได้ตัวเดียว ต่างจาก class ที่ใช้ซ้ำกับหลาย element ได้ · จำให้ขึ้นใจ: . = class และ # = id

5. Grouping selector A, B

เมื่อหลาย selector ต้องการสไตล์เดียวกัน ให้จัดกลุ่มรวมไว้ในกฎเดียวคั่นด้วยจุลภาค (,) แทนการเขียนกฎซ้ำหลายรอบ

#p1, .clsSp {
    color: coral;
}

6. Descendant selector A B

เลือก element ที่อยู่ข้างใน element อื่น โดยเขียนคั่นด้วยช่องว่าง เช่น article p { ... } จะมีผลเฉพาะ <p> ที่อยู่ภายใน <article> เท่านั้น

<style>
  article p { color: coral; }
</style>
<p>p นอก article — ไม่เปลี่ยนสี</p>
<article>
  <p>p ใน article — เป็นสี coral</p>
</article>
อย่าสับสน: ช่องว่าง กับ จุลภาค

article p (ช่องว่าง) = p ที่อยู่ใน article · article, p (จุลภาค) = article และ p ทุกตัว (grouping)

7. Pseudo-class selector

ใช้กำหนดสไตล์พิเศษของ element ในสถานะต่างๆ ตัวอย่างในสไลด์คือลิงก์

Selectorสถานะของลิงก์
aลิงก์ที่ยังไม่ได้คลิก
a:hoverตอนเมาส์ชี้อยู่บนลิงก์
a:activeตอนลิงก์กำลังถูกคลิก
 
<style>
  a        { color: blue; }
  a:hover  { color: orange; }
  a:active { color: red; }
</style>
<a href="#">ลองเอาเมาส์ชี้ แล้วกดค้างที่ลิงก์นี้</a>

นอกจากนี้ยังมี Combinator selectors (เลือกตามความสัมพันธ์ระหว่าง element), Pseudo-elements selectors (เลือกและจัดสไตล์เฉพาะบางส่วนของ element) และ Attribute selectors (เลือกตาม attribute หรือค่าของ attribute) — เป็นหัวข้อขั้นสูงที่สไลด์แนะนำให้ศึกษาเพิ่มเติมที่ W3Schools

ลองเล่น: selector นี้เลือก element ไหนบ้าง

กดเลือก selector แล้วดูว่า element ใดในโครงด้านล่างถูกเลือก (ใช้ querySelectorAll จริง)
<h1> หัวข้อ
<p id="p1"> ย่อหน้าแรก
<p class="clsSp"> ย่อหน้าที่สอง
<span class="clsSp"> ข้อความใน span
<article>
<p> ย่อหน้าใน article
<p class="line red"> อีกย่อหน้าใน article

CSS Specificity — เมื่อกฎหลายข้อชี้ element เดียวกัน

ถ้ามีกฎ CSS หลายกฎที่ขัดแย้งกันและชี้ไปที่ element เดียวกัน browser จะเลือกใช้กฎตามความเฉพาะเจาะจง (specificity) ของ selector

กฎ Specificity

ID selector เฉพาะเจาะจงสูงสุด > class selector > element selector

ถ้าความเฉพาะเจาะจงเท่ากัน กฎที่ประกาศทีหลังสุด (the latest rule) จะถูกนำไปใช้

ตัวอย่างที่ 1 — selector ต่างระดับกัน: <p> ตัวเดียวถูกชี้โดยทั้ง element, class และ id ผลที่ได้คือสีจาก #p1 เพราะ ID เฉพาะเจาะจงสูงสุด (แม้จะเขียนไว้ก่อนกฎอื่น)

<style>
  #p1    { color: blue; }
  .clsSp { color: green; }
  p      { color: coral; }
</style>
<p id="p1" class="clsSp">ข้อความนี้เป็นสีอะไร? (blue จาก #p1)</p>

ตัวอย่างที่ 2 — selector ระดับเดียวกัน: มี element selector p สองกฎ ความเฉพาะเจาะจงเท่ากัน จึงใช้กฎที่เขียนทีหลังสุด

<style>
  p { color: coral; }
  p { color: purple; }   /* ประกาศทีหลังสุด → ชนะ */
</style>
<p>ข้อความนี้เป็นสี purple</p>

External CSS Internal CSS Inline CSS Cascading Order

1. External CSS

กำหนด CSS ทั้งหมดไว้ในไฟล์ .css แยกต่างหาก แล้วเชื่อมไฟล์นั้นเข้ากับ HTML ด้วย <link> ในส่วน <head>

<head>
    <link rel="stylesheet" href="myStyle.css" />
</head>
/* ไฟล์ myStyle.css */
body {
    background-color: red;
    font-family: Arial;
}
ข้อดี

ไฟล์ CSS 1 ไฟล์ใช้ร่วมกับหลายไฟล์ HTML ได้ จึงประหยัดความพยายามมากที่สุดเมื่อต้องแก้สไตล์ทั้งเว็บไซต์

2. Internal CSS

กำหนด CSS ทั้งหมดไว้ใน <style>...</style> ภายในส่วน <head> ของเอกสาร HTML นั้นๆ — เหมาะกับหน้าที่มีสไตล์เฉพาะตัวและไม่ใช้ร่วมกับหน้าอื่น

<head>
    <style>
        body { background-color: red; }
    </style>
</head>

3. Inline CSS

กำหนด CSS ผ่าน attribute style ของ element นั้นโดยตรง (เขียน declaration ลงในค่าของ attribute)

<div style="background-color: gray;">
  <p style="color: white; font-size: 10em;">Hi</p>
</div>

Cascading Order — ลำดับความสำคัญเมื่อสไตล์ซ้อนกัน

เมื่อ element เดียวถูกกำหนดสไตล์มากกว่า 1 ทาง ลำดับความสำคัญจากมากไปน้อยคือ

  1. Inline CSS (attribute style)
  2. Internal CSS และ External CSS (สำคัญเท่ากัน — ดูข้อควรระวัง)
  3. Browser Default (สไตล์เริ่มต้นของ browser)
Inline CSS > Internal CSS > External CSS > Browser Default
ข้อที่มักเข้าใจผิด

Internal CSS กับ External CSS มีความสำคัญเท่ากัน — Internal ไม่ได้ชนะ External เสมอไป ตัวที่ถูกประกาศทีหลังในเอกสาร (ไม่ว่าจะเป็น <style> หรือ <link>) คือตัวที่มีผลจริง

เช่น ถ้าวาง <link> ไว้หลัง <style> ค่าจาก external CSS จะ override internal CSS ที่ชี้ไปยัง element เดียวกัน

<style> มาทีหลัง → Internal มีผล
<head>
  <link rel="stylesheet" href="myStyle.css" />
  <style> p { color: green; } </style>
</head>
<link> มาทีหลัง → External มีผล
<head>
  <style> p { color: green; } </style>
  <link rel="stylesheet" href="myStyle.css" />
</head>

ตัวอย่างที่ลองได้ในหน้านี้ (Inline เทียบ Internal): <style> กำหนดให้ p เป็นสีเขียว แต่ <p> ตัวที่สองมี attribute style สีแดง จึงเป็นสีแดงเพราะ Inline สำคัญที่สุด

<style>
  p { color: green; }
</style>
<p>Internal CSS → สีเขียว</p>
<p style="color: red;">Inline CSS ชนะ → สีแดง</p>

Font-related properties

Propertyใช้ทำอะไร / ค่าที่ใช้
colorสีตัวอักษร
font-familyแบบอักษร เลือกได้ทั้ง specific font เช่น Arial, Courier New หรือ generic font family ที่แทบทุก browser รองรับ

<style>

<p class="a">Arial 20px สี navy</p>

<p class="c">1.5em ตัวเอียง</p>

Propertyใช้ทำอะไร

border-styleรูปแบบเส้น เช่น solid, dotted, dashed, hidden ฯลฯ

<style>

  .solid  { border-style: solid; border-radius: 12px; }
  .dotted { border-style: dotted; }

</style>
<div class="solid">solid + border-radius 12px</div>
<div class="dotted">dotted</div>
<div class="dashed">dashed + มุมโค้งเฉพาะบางมุม</div>

CSS Box Model

ทุก element ใน CSS ถูกมองเป็นกล่อง ประกอบด้วย 4 ชั้น เรียงจากในสุดไปนอกสุด

Margin — พื้นที่ว่างรอบนอกสุด (ระยะห่างจาก element อื่น)
Border — เส้นขอบ
Padding — พื้นที่ว่างรอบเนื้อหา
Content — เนื้อหาจริง
ในสุด → นอกสุด: Content → Padding → Border → Margin
Shorthand property: border

border เป็น shorthand property ที่รวม width / style / color ไว้ในบรรทัดเดียว เช่น border: 5px solid gray;

<style>
  .box {
    background-color: lightyellow;
    padding: 20px;
    border: 5px solid gray;
    margin: 25px;
  }
</style>
<div class="box">Content: padding 20px · border 5px · margin 25px</div>

Dimension: width และ height

width และ height กำหนดขนาดของ element ได้ 2 แบบ

Fixed

หน่วย px — ขนาดคงที่ ไม่เปลี่ยนตาม container

Relative

หน่วย % — ขนาดสัมพัทธ์กับ container ของมัน

<style>
  div { background-color: lightblue; margin: 6px 0; height: 30px; }
  .fixed    { width: 200px; }
  .relative { width: 50%; }
</style>
<div class="fixed">width: 200px</div>
<div class="relative">width: 50% ของ container</div>

CSS Units

Absolute length units

ขนาดคงที่แน่นอน เช่น cm, mm, in, px, pt

Relative length units

ขนาดสัมพัทธ์กับ property อื่น เช่น em (สัมพัทธ์กับ font-size), rem, vm, %

ทำไมใช้หน่วย relative

หน่วย relative อย่าง em / rem ช่วยสร้าง layout ที่ยืดหยุ่นและสเกลได้ดีบนอุปกรณ์ต่างชนิดกัน

ตัวอย่าง em: ข้อความใน <span> ขนาด 2em คือ 2 เท่าของ font-size ของ element แม่ — ถ้าแม่เปลี่ยนขนาด ลูกก็เปลี่ยนตาม

<style>
  .small { font-size: 12px; }
  .big   { font-size: 20px; }
  span   { font-size: 2em; }
</style>
<p class="small">แม่ 12px → <span>ลูก 2em</span></p>
<p class="big">แม่ 20px → <span>ลูก 2em</span></p>

Float และ Clear

float: left | right | none;

ทำให้ element "ลอย" ไปด้านที่กำหนด แล้วให้ element อื่นไหลมาล้อมรอบได้

clear: left | right | both | none;

กำหนดว่าไม่อนุญาตให้มี float element อยู่ด้านที่ระบุของ element นี้ — ป้องกันการไหลทับกัน

<style>
  .pic   { float: left; width: 80px; height: 60px; margin-right: 10px; background-color: coral; }
  .clear { clear: left; background-color: lightgray; }
</style>
<div class="pic"></div>
<p>ข้อความนี้ไหลมาล้อมรอบกล่องสี coral ที่ float: left

CSS in Action: Alignment (จัดตำแหน่ง)

section { width: 80%; margin: auto; } ทำให้ section กว้าง 80% ของ container และ margin: auto ทำให้อยู่กึ่งกลางแนวนอน จากนั้นเพิ่ม padding และ border ให้ <p> ข้างใน ช่วยให้อ่านง่ายและแบ่งส่วนชัดเจนขึ้น

<style>
  body    { background-color: whitesmoke; }
  section { width: 80%; margin: auto; background-color: white; }
  p       { padding: 10px; border: 2px solid lightgray; }
</style>
<section>
  <p>section กว้าง 80% และอยู่กึ่งกลางด้วย margin: auto</p>
  <p>padding + border ช่วยแบ่งส่วนให้อ่านง่าย</p>
</section>
จุดที่ต้องจำ

margin: auto จัด element ให้อยู่กึ่งกลางแนวนอนของ container เมื่อกำหนด width แล้ว (ในตัวอย่างคือ 80%)

CSS in Action: Navigation bar

display: block; ทำให้ element ขึ้นบรรทัดใหม่และกินพื้นที่เต็มความกว้าง จึงใช้จัด <a> ใน <nav> ให้เป็นเมนูแนวตั้งเต็มแถบได้ และใช้ text-decoration: none; ลบขีดเส้นใต้ของลิงก์ออก

<style>
  nav   { width: 200px; background-color: #333; }
  nav a { display: block; padding: 10px; color: white; text-decoration: none; }
  nav a:hover { background-color: coral; }
</style>
<nav>
  <a href="#">Home</a>
  <a href="#">News</a>
  <a href="#">Contact</a>
</nav>

04 Cascading Order

Inline > Internal ≈ External > Default

Internal กับ External สำคัญเท่ากัน — ตัวที่ประกาศทีหลังในเอกสาร (<style> หรือ <link>) มีผล

<link> อยู่หลัง <style> → External override Internal

01โครงสร้างไวยากรณ์ CSS ประกอบด้วยส่วนใดบ้าง?

กฎ CSS = selector (ชี้ element) + declaration block { property: value; } ที่ครอบด้วยวงเล็บปีกกา

02Selector แบบ Universal (*) มีผลอย่างไร?

* เลือกทุก element ในหน้า เช่น * { text-align: center; color: coral; }

03Selector .clsSp เลือก element ใด?

จุด (.) นำหน้า = class selector → มีผลกับทุก element ที่มี class="clsSp" · ส่วน id ใช้ #

04Selector #p1 เลือก element ใด?

hash (#) นำหน้า = ID selector → มีผลเฉพาะ element ที่มี id="p1" (id ต้องไม่ซ้ำกันในหน้า)

05Selector "article p" (เว้นวรรค) หมายถึงอะไร?

Descendant selector เขียนคั่นด้วยช่องว่าง: article p = <p> ที่อยู่ภายใน <article> · ถ้าคั่นด้วยจุลภาคจะเป็น grouping

06Pseudo-class a:hover ใช้ทำอะไร?

a = ลิงก์ที่ยังไม่ได้คลิก · a:hover = ตอนเมาส์ชี้อยู่ · a:active = ตอนกำลังถูกคลิก

07หลักการ CSS Specificity ข้อใดถูกต้อง?

ลำดับ specificity: ID > class > element

08เมื่อ specificity เท่ากัน กฎ CSS ใดจะถูกใช้?

ถ้าความเฉพาะเจาะจงเท่ากัน the latest rule (กฎที่ประกาศทีหลังสุด) จะถูกนำไปใช้

09วิธีการเพิ่ม CSS เข้า HTML มีกี่แบบ อะไรบ้าง?

External (ไฟล์ .css + <link>), Internal (<style> ใน <head>) และ Inline (attribute style)

10External CSS เชื่อมกับ HTML ด้วย tag ใด และอยู่ที่ส่วนใด?

<link rel="stylesheet" href="myStyle.css" /> วางไว้ในส่วน <head>

11ลำดับความสำคัญของ Cascading Order (จากสูงสุดไปต่ำสุด)?

Inline CSS > Internal CSS > External CSS > Browser Default (โดย Internal กับ External จริงๆ สำคัญเท่ากัน ตัดสินด้วยลำดับที่ประกาศ)

12Internal CSS กับ External CSS อันไหนสำคัญกว่ากัน?

สำคัญเท่ากัน — ตัวที่ถูกประกาศทีหลังในเอกสาร (<style> หรือ <link>) มีผลจริง เช่น <link> อยู่หลัง <style> → external override internal

13ใน CSS Box Model เรียงจากในสุดไปนอกสุดคือข้อใด?

Content (เนื้อหา) → Padding (ว่างรอบเนื้อหา) → Border (เส้นขอบ) → Margin (ว่างรอบนอกสุด)

14หน่วยใดต่อไปนี้เป็น Absolute length unit?

Absolute: cm, mm, in, px, pt · Relative: em, rem, vm, %

15หน่วย em สัมพันธ์กับอะไร?

em เป็น relative length unit ที่สัมพัทธ์กับ font-size

16CSS property float: left; ทำอะไร?

float ทำให้ element "ลอย" ไปด้านที่กำหนด แล้ว element อื่นไหลมาล้อมรอบได้

17CSS property clear: left; มีผลอย่างไร?

clear กำหนดว่าไม่อนุญาตให้มี float element อยู่ด้านที่ระบุของ element นี้ (ป้องกันการไหลทับกัน)

18display: block; มีผลต่อ element อย่างไร?

display: block ทำให้ element ขึ้นบรรทัดใหม่และกินพื้นที่เต็มความกว้าง — ใช้จัด <a> ใน <nav> เป็นเมนูแนวตั้ง

19property margin: auto; มีผลอย่างไรเมื่อกำหนด width แล้ว?

section { width: 80%; margin: auto; } → กว้าง 80% และอยู่กึ่งกลางแนวนอน

20text-decoration: none; มักใช้กับ tag ใดเพื่อลบขีดเส้นใต้?

ใช้กับลิงก์ <a> (เช่นใน navigation bar) เพื่อลบขีดเส้นใต้ลิงก์ออก
