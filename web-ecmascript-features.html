Promises

นิยามจากสไลด์

object ชนิด Promise แทนการเสร็จสิ้น (หรือความล้มเหลว) ในอนาคตของงาน asynchronous พร้อมค่าผลลัพธ์ของมัน

Producing code

ทำบางอย่างที่ใช้เวลา เช่น โหลดข้อมูลจากฐานข้อมูล

Consuming code

รับผลลัพธ์จาก producing code เมื่อมันพร้อม

Promise object คือตัวเชื่อมระหว่าง producing code กับ consuming code

สถานะของ promise มี 3 แบบ

pending
สถานะเริ่มต้น — ยังไม่ fulfilled และไม่ rejected
fulfilled
งานสำเร็จ
rejected
งานล้มเหลว

ไวยากรณ์ constructor — resolve และ reject เป็น callback ที่ JavaScript engine เตรียมไว้ให้ โค้ดของเราอยู่ใน executor เท่านั้น

let promise = new Promise(function (resolve, reject) {
  // executor (the producing code)
});
resolve(value)
งานเสร็จสำเร็จ พร้อมผลลัพธ์ value
reject(error)
เกิดข้อผิดพลาด โดย error คือ object ของ error

ตัวอย่างจากสไลด์ (producing code) — สไลด์ตั้ง x = 5 ซึ่งไม่เท่ากับ 0 โค้ดจึงเข้า else และจบที่สถานะ rejected

let myPromise = new Promise(function (resolve, reject) {
  let x = 5;
  if (x == 0) {
    // after 1 second signal that the job is done with the result "finished"
    setTimeout(() => resolve("finished"), 1000);
  } else {
    // after 1 second signal that the job is finished with an error
    setTimeout(() => reject(new Error("No No!")), 1000);
  }
});

myPromise.then(
  function (value) { console.log("fulfilled:", value); },
  function (error) { console.log("rejected:", error.message); }
);

Consuming code: then, catch และ finally

function ฝั่งผู้บริโภคผลลัพธ์ลงทะเบียน (subscribe) ได้ด้วย method .then, .catch และ .finally

  • argument ตัวแรกของ .then คือ function ที่ทำงานเมื่อ promise ถูก resolve และรับผลลัพธ์มา
  • argument ตัวที่สองของ .then คือ function ที่ทำงานเมื่อ promise ถูก reject และรับ error มา
promise.then(
  function (result) { /* handle a successful result */ },
  function (error)  { /* handle an error */ }
);

ถ้าต้องการเน้นที่ error หรือสนใจเฉพาะ error ใช้ .catch ได้

myPromise.then(
  function (value) {
    Display(value);
  }
)
.catch((error) => alert(error));

The spread operator (...)

array, object หรือ string ถูกกระจายออกได้ด้วย spread operator ...

const a = [1, 2, 3];              // a = 1,2,3
const b = [...a, 4, 5, 6];        // b = 1,2,3,4,5,6
const c = [...a];                 // c = 1,2,3  (คัดลอก array)

const message = "Hello";          // message = Hello
const arrayized = [...message];   // arrayized = H,e,l,l,o

console.log(b.join(","));
console.log(c.join(","));
console.log(arrayized.join(","));

Function Rest Parameter

rest parameter (...) ทำให้ function รับ argument ได้ไม่จำกัดจำนวน — ใช้สัญลักษณ์เดียวกับ spread operator

function findMax(...args) {
  let max = 0;
  for (let arg of args) {
    max = max < arg ? arg : max;
  }
  return max;
}

console.log(findMax(3, 9, 2));
console.log(findMax(1, 4, 7, 2, 6));

ES2017: String padding

ES2017 เพิ่ม method ของ String มา 2 ตัว: padStart และ padEnd

padStart(targetLength [, padString])
padEnd(targetLength [, padString])
let string = "World";
console.log(string.padStart(10));            // "     World"
console.log(string.padStart(10, "Hello"));   // "HelloWorld"
console.log(string.padEnd(10));              // "World     "
console.log(string.padEnd(10, "Hello"));     // "WorldHello"

ไล่ทีละขั้น — "World" ยาว 5 ตัว ต้องการความยาวรวม 10 จึงเติมอีก 5 ตัว: ถ้าไม่ระบุ padString จะเติมช่องว่าง ถ้าระบุ "Hello" จะเติม Hello ไว้ด้านหน้า (padStart) หรือด้านหลัง (padEnd)

ES2017: Object.values() และ Object.entries()

Object.values()
คืน array ของค่าของ properties ทั้งหมดใน object

คืน array ของคู่ key-value ของ properties ทั้งหมดใน object
const person = {
  firstName: "Wudhichart",
  lastName: "Sawangphol",
  lecturer: true,
  age: 30,

let vals = Object.values(person);
console.log(vals);
// ["Wudhichart", "Sawangphol", true, 30]

let ents = Object.entries(person);

ES2017: getOwnPropertyDescriptors() และ Trailing commas

Object.getOwnPropertyDescriptors() คืน descriptor ของ property ทุกตัวที่เป็นของ object นั้นเอง — ใช้คู่กับ Object.defineProperties() เพื่อคัดลอก property ไปยัง object ใหม่ได้

const person = {
  firstName: "Wudhichart",
  lastName: "Sawangphol",
  lecturer: true,
  age: 30,
};

const person2 = {};
Object.defineProperties(person2, Object.getOwnPropertyDescriptors(person));

console.log(person2);
// person2 = { firstName: "Wudhichart", lastName: "Sawangphol", lecturer: true, age: 30 }

Trailing commas — ES2017 อนุญาตให้มีเครื่องหมายจุลภาคปิดท้ายได้ทั้งใน function declaration และ function call

  firstName: "Wudhichart",
  lastName: "Sawangphol",

  age: 30,          // <- จุลภาคตัวนี้ไม่ทำให้ error
};

ES2017: Async functions (async / await)

  • async/await เป็นไวยากรณ์พิเศษที่ทำงานกับ promise
  • คำว่า async หน้า function หมายความว่า function นั้นคืนค่าเป็น promise เสมอ
  • คำว่า await ทำให้ JavaScript รอจนกว่า promise นั้นจะ settle แล้วคืนผลลัพธ์ออกมา

ตัวอย่างจากสไลด์ — คราวนี้ x = 0 จึงเข้า if และ resolve ด้วยค่า "finished"

let myPromise = new Promise(function (resolve, reject) {
  let x = 0;
  if (x == 0) {
    setTimeout(() => resolve("finished"), 1000);
  } else {
    setTimeout(() => reject(new Error("No No!")), 1000);
  }
});

function resolveAfter1second() {
  return myPromise;
}

const asyncFunction = async () => {
  console.log(await resolveAfter1second());
};

console.log("Before");
asyncFunction();
console.log("After");
// Before
// After
// finished
ทำไมลำดับเป็น Before → After → finished

asyncFunction() ไปติดอยู่ที่ await แล้วคืนการควบคุมกลับมาทันที บรรทัด console.log("After") จึงทำงานก่อน ส่วน finished ค่อยพิมพ์เมื่อ promise settle หลัง 1 วินาที

async function f() {
  return 2;
}
f().then(alert);

ES2019: flat, flatMap, fromEntries, trimStart/trimEnd

Array.prototype.flat() — ทำให้ array หลายมิติแบนลง โดยรับระดับความลึกเป็น argument

const array = ["Apple", "Orange", ["Grape", ["Pineapple"]]];

// ["Apple", "Orange", "Grape", Array(1)]   ← ยังเหลือ array ซ้อนอยู่ 1 ชั้น

console.log(array.flat(2));
// ["Apple", "Orange", "Grape", "Pineapple"]

flatMap() เป็น method ของ Array ที่รวม flat() กับ map() เข้าด้วยกัน

const numbers = [1, 2, 3, 4, 5, 6];

console.log(numbers.map((num) => [num, num * 2]));
// [Array(2), Array(2), Array(2), Array(2), Array(2), Array(2)]

console.log(numbers.flatMap((num) => [num, num * 2]));
// [1, 2, 2, 4, 3, 6, 4, 8, 5, 10, 6, 12]

ES2020: Nullish coalescing operator (??)

operator ?? ให้ค่า default เมื่อตัวแปรเป็น null หรือ undefined

const name = "Wudhichart";
const nullish = null;

const name2 = name ?? "Jidapa";       // Wudhichart
const name3 = nullish ?? "Jidapa";    // Jidapa

console.log(name2);
console.log(name3);

ES2020: Optional chaining operator (?.)

operator ?. จัดการกับ null และ undefined ใน object — ถ้าเจอก็คืน undefined แทนที่จะ error

const obj = {
  prop: {
    subLevelProp: {
      value: "Wudhichart",
    },
  },
};

console.log(obj.prop.subLevelProp.value);        // Wudhichart
console.log(obj?.prop?.subLevelProp?.value);     // Wudhichart
console.log(obj?.prop?.secondsubLevelProp?.value); // undefined
console.log(obj.prop.secondsubLevelProp.value);  // error

ใช้กับ array ได้ด้วย

const cars = null;

console.log(cars?.[3]);   // undefined
console.log(cars[3]);     // TypeError: Cannot read property '3' of null

ES2020: String.matchAll()

ใช้ค้นหาทุกตำแหน่งที่ตรงกับ regular expression เดียวกันใน string

const regexg = /\b(orange)+\b/g;
const fruits = "orange, banana, orange, apple, orange, apple";
const matched = fruits.matchAll(regexg);

for (const result of matched) {
  console.log(result[0], "ที่ตำแหน่ง", result.index);

&&= (logical AND assignment)
ประเมิน operand ขวาและกำหนดให้ตัวซ้าย ก็ต่อเมื่อตัวซ้ายเป็น truthy
||= (logical OR assignment)
ประเมิน operand ขวาและกำหนดให้ตัวซ้าย ก็ต่อเมื่อตัวซ้ายเป็น falsy
??= (nullish coalescing assignment)
ประเมิน operand ขวาและกำหนดให้ตัวซ้าย ก็ต่อเมื่อตัวซ้ายเป็น nullish (null หรือ undefined)
// &&=  ตัวซ้าย truthy จึงรับค่าใหม่ / falsy จึงคงค่าเดิม
let x = 1, y = 0, z = 5;
x &&= z; console.log(x);   // 5
y &&= z; console.log(y);   // 0

// ||=  ตัวซ้าย truthy จึงคงค่าเดิม / falsy จึงรับค่าใหม่
y = 0; x = 1; z = 5;
x ||= z; console.log(x);   // 1
y ||= z; console.log(y);   // 5

// ??=  ตัวซ้ายมีค่าอยู่แล้วจึงคงเดิม / ยังไม่มีจึงรับค่าใหม่
const a = { age: 36 };
a.age ??= 20;    console.log(a.age);      // 36
a.height ??= 175; console.log(a.height);  // 175

Well-formed Unicode Strings — การจัดการ Unicode ใน JS มักมีความไม่สอดคล้องกัน โดยเฉพาะกับตัวอักษรจากหลายภาษาและสัญลักษณ์ · string ที่รูปแบบผิดทำให้เกิดปัญหาที่คาดไม่ถึงในแอปที่ใช้งานทั่วโลกหรือพึ่งพา API

const problematicString = "test \uD800";
console.log(problematicString);
console.log(problematicString.toWellFormed());

toWellFormed() ทำให้การจัดการ Unicode น่าเชื่อถือสำหรับแอปที่รับ input จากหลายภาษาหรือชุดอักขระซับซ้อน ลด encoding error และเข้ากันข้ามแพลตฟอร์มได้ดีขึ้น

Atomic waitSync — การออกแบบแบบ single-threaded ของ JS ทำให้จัดการ concurrency ยาก โดยเฉพาะเมื่อแชร์หน่วยความจำระหว่าง thread ใน worker · ES2024 เสนอเทคนิคด้วย waitSync ที่ให้ thread หยุดรอจนกว่าเงื่อนไขใน shared memory จะเป็นจริง เพื่อรับประกันการซิงก์และความถูกต้องของข้อมูล

const sharedArray = new Int32Array(new SharedArrayBuffer(1024));

function performSynchronizedOperation(index, value) {
  Atomics.waitSync(sharedArray, index, 0);  // Wait until condition is met
  sharedArray[index] = value;
  Atomics.notify(sharedArray, index, 1);    // Notify other threads of the update
}

const data = await fetchData();

Decorators — function ที่เสริมความสามารถให้ method เดิม โดยแก้พฤติกรรมของ object ได้โดยไม่ต้องแก้โค้ดต้นฉบับ · มักใช้กับ class และนำหน้าด้วยสัญลักษณ์ @

// A simple decorator

  console.log(`Logging ${key} function`);
  return descriptor;
}

    console.log("Hello, world!");

ES2024: Temporal API

object Date ถูกมองว่าใช้งานยุ่งยากและเป็นปัญหาเรื้อรังของ JavaScript จนเกิด library อย่าง moment.js และ date-fns ขึ้นมาช่วย · Date เดิมทีลอกมาจาก Java ซึ่งภายหลัง Java เลิกใช้ไปแล้ว แต่ JavaScript ยังเก็บไว้เพื่อ backward compatibility และไม่ถูกปรับปรุงเลยตั้งแต่เริ่มมี

ทำไมต้องใช้ Temporal API

Comprehensive Features
ชุดความสามารถที่ครอบคลุมกว่า object Date เดิม
Native Time Zone Support
รองรับ time zone ทุกเขตในตัว ทำให้คำนวณวันเวลาข้ามภูมิภาคได้แม่นยำ

ไม่ต้องพึ่ง library ภายนอก พัฒนาง่ายขึ้นและประสิทธิภาพดีขึ้น

ความสามารถหลัก: รองรับ time zone อย่างเต็มรูปแบบ · parse string ที่รูปแบบเข้มงวดได้อย่างน่าเชื่อถือ · รองรับ ปฏิทินที่ไม่ใช่ Gregorian · คำนวณวันเวลาได้ง่ายขึ้น

Temporal API ยังอยู่ในขั้นทดลอง — ปัจจุบันอยู่ที่ Stage 3 ของกระบวนการ TC39 คือใกล้เสร็จแต่ยังไม่เป็นส่วนหนึ่งของมาตรฐาน ECMAScript อย่างเป็นทางการ

Import Attributes / JSON Modules — ES2025 ทำให้การ import ไฟล์ JSON เป็น module โดยตรง เป็นทางการ พร้อม attribute บอก runtime ว่าจะจัดการไฟล์อย่างไร

// Synchronous import
import config from './config.json' with { type: 'json' };

// Dynamic import

Iterator Helpers — method ใหม่สำหรับ functional programming แบบ lazy บน iterator · ไม่สร้าง array ทันทีเหมือน .map()/.filter() ของ array จึงเหมาะกับ pipeline ที่ประมวลผล data stream อย่างมีประสิทธิภาพ

const it = Iterator.from([1, 2, 3, 4, 5])
  .filter(n => n % 2 === 0)   // keep evens
  .map(n => n * n)            // square
  .take(2);                   // first two

console.log(it.toArray());    // [4, 16]

Set Methods and Relationships — Set ได้การดำเนินการทางเซตแบบคณิตศาสตร์มาในตัว

const A = new Set([1, 2, 3]);
const B = new Set([3, 4, 5]);

console.log(A.union(B));                // Set {1, 2, 3, 4, 5}
console.log(A.intersection(B));         // Set {3}
console.log(A.difference(B));           // Set {1, 2}
console.log(A.symmetricDifference(B));  // Set {1, 2, 4, 5}
console.log(A.isSubsetOf(B));           // false
console.log(A.isDisjointFrom(B));       // false

RegExp Enhancements

  • RegExp.escape() — escape string อย่างปลอดภัยก่อนนำไปใช้ใน regex
  • Inline RegExp Modifiers — ใส่ flag ให้เฉพาะบางส่วนของ regex
  • Duplicate Named Capture Groups — ใช้ชื่อ group ซ้ำกันข้าม alternative ได้แล้ว
const userInput = "hello.*+?^${}()|[]\\world";
const safe = RegExp.escape(userInput);
console.log(safe);  // "hello\.\*\+\?\^\$\{\}\(\)\|\[\]\\world"

const re = /a(?i:b)c/;                 // only 'b' is case-insensitive
console.log("aBc".match(re));          // match

const re2 = /(?:(?<num>\d+)|(?<num>[a-z]+))/;
console.log("123".match(re2).groups.num);  // "123"
console.log("abc".match(re2).groups.num);  // "abc"

Promise.try() — วิธีมาตรฐานในการห่อ function ที่อาจ throw แบบ synchronous หรือคืน Promise เพื่อให้ exception ถูกจัดการเป็น promise rejection อย่างถูกต้อง

function mayThrow() {
  if (Math.random() > 0.5) throw new Error("Oops");
  return 42;
}

Promise.try(() => mayThrow())
  .then(val => console.log("Value:", val))
  .catch(err => console.error("Caught:", err.message));

Float16 Support — typed array ตัวใหม่ Float16Array พร้อม method จัดการ float ความละเอียดครึ่ง (16 บิต) · ใช้หน่วยความจำครึ่งหนึ่งของ Float32Array และหนึ่งในสี่ของ Float64Array

const arr = new Float16Array([0.1, 0.2, 0.3]);
console.log(arr[0]);          // approximated float16 value

const dv = new DataView(new ArrayBuffer(2));
dv.setFloat16(0, Math.PI);

ES2026: sumPrecise, Error.isError, fromAsync, getOrInsert, rawJSON, Base64

ES2026 ประกอบด้วย: Math.sumPrecise() · Error.isError() · Array.fromAsync() · Map.getOrInsert() · JSON.rawJSON() · Base64 และ hexadecimal encoding สำหรับ Uint8Array

Math.sumPrecise() — เลขทศนิยมใน JavaScript ขึ้นชื่อเรื่องความไม่แม่นยำ · method นี้คำนวณผลบวกที่แม่นยำของ iterable ของตัวเลขโดยไม่สูญเสียความละเอียด ทำให้งานการเงินและวิทยาศาสตร์เชื่อถือได้โดยไม่ต้องใช้ library ภายนอก

// The Old Way (Inaccurate)
const numbers = [1e16, 1, -1e16];
const badSum = numbers.reduce((a, b) => a + b);
// badSum === 0 (เลข 1 หายไป เพราะ 1e16 + 1 ถูกปัดกลับเป็น 1e16)
console.log("badSum:", badSum);

// ES2026: The New Way (Precise)
const exactSum = Math.sumPrecise(numbers);
// exactSum === 1
console.log("exactSum:", exactSum);
ยังไม่รองรับในเบราว์เซอร์

Math.sumPrecise เป็นข้อเสนอที่ใหม่มากและยังไม่รองรับในเบราว์เซอร์ทุกตัว — ถ้ารันตอนนี้มักได้ Math.sumPrecise is not a function ต้องเพิ่ม <script> ที่ import core-js polyfill ก่อน

Error.isError() — การตรวจว่าค่าที่ถูก throw เป็น Error จริงหรือไม่นั้นยาก เพราะ instanceof Error ใช้ไม่ได้ข้าม Realm (เช่น iframe หรือ Web Worker) · Error.isError(value) เป็นกลไกในตัวที่ตรวจได้อย่างน่าเชื่อถือไม่ว่า error จะมาจากที่ใด

// 1. สร้าง iframe (คนละ "Realm")
const iframe = document.createElement('iframe');
iframe.style.display = 'none';
document.body.appendChild(iframe);

// 2. เอา Error constructor จาก realm ของ iframe มา
const IframeError = iframe.contentWindow.Error;

try {
  // 3. จำลอง function ที่ throw error จาก iframe นั้น
  throw new IframeError('Something went wrong in the iframe!');
} catch (err) {
  // แบบเดิม: ล้มเหลว เพราะ prototype chain ชี้ไปที่ Error ของ iframe ไม่ใช่ของ window เรา
  console.log('err instanceof Error:', err instanceof Error);   // false
  // ES2026: ตรวจข้าม realm ได้อย่างปลอดภัย
  console.log('Error.isError(err):', Error.isError(err));       // true
}

Array.fromAsync() — เดิมต้องวน for await...of แล้ว push เข้า array เองซ้ำๆ · method นี้สร้าง Array ใหม่จาก async iterable, iterable หรือ array-like ได้ในตัว

// Fetching pages of data natively
const data = await Array.fromAsync(asyncDataStream());

Map.getOrInsert() — เดิมต้องเขียนเงื่อนไขยืดยาว (เช็ค .has() แล้ว .set() แล้ว .get()) · method นี้อ่านค่าของ key ที่ให้มา หรือคำนวณและใส่ค่า default ลงไปถ้ายังไม่มี key นั้น

// The Old Way (Verbose Boilerplate)
const oldVisits = new Map();
const user1 = 'user_123';
if (!oldVisits.has(user1)) {
  oldVisits.set(user1, { count: 0 });
}
const oldStats = oldVisits.get(user1);
oldStats.count++;
console.log('Old Way visits:', oldVisits.get(user1).count);   // 1

// ES2026: The New Way (Elegant)
const newVisits = new Map();
const user2 = 'user_456';
const newStats = newVisits.getOrInsert(user2, { count: 0 });
newStats.count++;
console.log('New Way visits:', newVisits.get(user2).count);   // 1

JSON.rawJSON() — การ parse JSON ที่มีตัวเลขใหญ่มาก (เช่น id 64 บิต) ทำให้เกิดความคลาดเคลื่อนจากการปัดเศษ เพราะ JSON.parse() แปลงเป็น float ที่ไม่แม่นยำ · JSON.rawJSON() ให้เข้าถึงและ stringify ข้อความ JSON ดิบได้โดยตรง จึงไม่ทำให้ตัวเลขใหญ่เพี้ยน

// The Old Way (Inaccurate or crashes)
const oldPayload = {
  name: "System Node",
  id: 9007199254740993   // ถูกปัดลงเป็น 9007199254740992 โดย JavaScript
};
console.log('Old Way stringified:', JSON.stringify(oldPayload));

// ES2026: The New Way (JSON.rawJSON)
const newPayload = {
  name: "System Node",
  id: JSON.rawJSON("9007199254740993")
};
console.log('New Way stringified:', JSON.stringify(newPayload));
// Output: '{"name":"System Node","id":9007199254740993}'

Base64 และ hexadecimal encoding ของ Uint8Array — เดิมต้องใช้ btoa()/atob() ซึ่งทำงานกับ string ไม่ใช่ byte หรือพึ่ง package ภายนอกที่หนัก · ตอนนี้ method encoding/decoding แบบ Base64 และ Hexadecimal ถูกเพิ่มเข้า prototype ของ Uint8Array โดยตรง

const bytes = new Uint8Array([72, 101, 108, 108, 111]);  // "Hello" in ASCII

// The Old Way (Verbose and often performance heavy)
const oldBase64 = btoa(String.fromCharCode(...bytes));   // Warning: Fails on very large arrays!
const oldHex = Array.from(bytes).map(b => b.toString(16).padStart(2, '0')).join('');

// ES2026: The New Way (Native, safe, and performant)
const base64Str = bytes.toBase64();
const hexStr = bytes.toHex();

// Native Decoding back to Uint8Array
const decodedFromBase64 = Uint8Array.fromBase64(base64Str);
const decodedFromHex = Uint8Array.fromHex(hexStr);
console.log('Decoded match:', decodedFromBase64[0] === 72);

01ECMAScript (ES) ถูกกำหนดมาตรฐานโดยองค์กรใด?

สไลด์ระบุว่า ECMAScript is a general-purpose programming language standardized by Ecma International และ JavaScript คือ implementation ของ ES ที่นิยมและถูกใช้มากที่สุด

02ES6 มีชื่อทางการ (official name) ว่าอะไร?

ES6 = ES2015 ออกเดือน June 2015 — ตั้งแต่รุ่นนี้เป็นต้นไปชื่อทางการเปลี่ยนมาใช้ปีที่เผยแพร่

03ECMAScript เวอร์ชันใดถูกยกเลิก (Abandoned) และไม่เคยถูกเผยแพร่ออกมา?

ตารางเวอร์ชันในสไลด์ระบุ ES4 ว่า Abandoned ส่วนรุ่นอื่นมีวันเผยแพร่ครบ

04promise มีสถานะ (state) อะไรบ้าง?

pending คือสถานะเริ่มต้นที่ยังไม่ fulfilled และไม่ rejected · fulfilled คืองานสำเร็จ · rejected คืองานล้มเหลว

05argument ตัวที่สองของ .then() ทำงานเมื่อใด?

argument ตัวแรกของ .then คือ function ที่ทำงานเมื่อ resolve ส่วนตัวที่สองคือ function ที่ทำงานเมื่อ reject และรับ error — ถ้าสนใจเฉพาะ error จะใช้ .catch แทนก็ได้

06Template Literals ใน ES6 ใช้เครื่องหมายอะไรครอบ string และฝัง expression อย่างไร?

Template Literals สร้าง string ด้วย backtick และฝัง expression ด้วย ${a_variable} เช่น `Hello, ${name}`

07ถ้า const a = [1, 2, 3]; แล้ว const b = [...a, 4, 5, 6]; ค่าใน b คืออะไร?

spread operator (...) กระจายสมาชิกของ a ออกมาเรียงต่อกับ 4, 5, 6 · ถ้าเขียน [...a] เฉยๆ จะได้สำเนาของ a

08ผลของ const arrayized = [..."Hello"]; คืออะไร?

spread operator ใช้กับ string ได้ — ผลคือแปลง string เป็น array ของตัวอักษร

09for-of loop ต่างจาก forEach() อย่างไร ตามที่สไลด์ระบุ?

สไลด์ระบุว่า unlike forEach(), you can use break, continue, and return — for-of วนผ่าน iterable object เช่น array

10WeakMap ต่างจาก Map ในเรื่อง key อย่างไร?

ตารางในสไลด์: Map มี Key Types เป็น any value ส่วน WeakMap เป็น Objects · WeakMap ยังไม่มี size และวนด้วย keys()/values()/entries() ไม่ได้

11Array.find() คืนค่าอะไร?

find() คืนค่าแรกที่ผ่านเงื่อนไข ส่วน findIndex() คืนตำแหน่งของค่าแรกที่ผ่านเงื่อนไข เช่น [10, 30, 25, 48].find(num => num < 30) ได้ 10

12Function Rest Parameter (...) ทำอะไร?

rest parameter ใช้สัญลักษณ์เดียวกับ spread operator แต่ทำงานตรงข้าม — รวบ argument ทั้งหมดเข้ามาเป็น array เช่น function findMax(...args)

13Array.includes() ที่เพิ่มมาใน ES2016 ต่างจาก indexOf อย่างไร?

ด้วย ES6 ต้องเช็คจาก indexOf ว่าค่าที่ได้เป็น -1 หรือไม่ ส่วน ES2016 ใช้ includes ซึ่งคืน boolean ตรงๆ

14ผลของ "World".padStart(10, "Hello") คืออะไร?

padStart เติมข้างหน้าให้ความยาวรวมครบ 10 — "World" ยาว 5 จึงเติม "Hello" ไว้ด้านหน้าได้พอดี · ถ้าใช้ padEnd(10, "Hello") จะได้ "WorldHello"

15Object.entries(person) คืนค่าอะไร?

Object.entries() คืน array ของคู่ key-value เช่น ["firstName", "Wudhichart"] ส่วน Object.values() คืน array ของเฉพาะค่า

16function ที่มีคำว่า async อยู่ข้างหน้า จะคืนค่าเป็นอะไรเสมอ?

สไลด์ระบุว่า the word async before a function means that a function always returns a promise ส่วน await ทำให้ JavaScript รอจนกว่า promise นั้นจะ settle

17Nullish coalescing operator (??) ให้ค่าทางขวาเมื่อใด?

สไลด์ระบุว่า this operator provides a default value when the variable is either null or undefined เช่น null ?? "Jidapa" ได้ "Jidapa" แต่ "Wudhichart" ?? "Jidapa" ได้ "Wudhichart"

18ถ้า const a = { age: 36 }; แล้วเขียน a.age ??= 20; ค่า a.age จะเป็นเท่าใด?

??= กำหนดค่าให้ตัวซ้ายก็ต่อเมื่อตัวซ้ายเป็น nullish (null หรือ undefined) — a.age มีค่า 36 อยู่แล้วจึงไม่ถูกเปลี่ยน · แต่ a.height ??= 175 จะได้ 175 เพราะยังไม่มีค่า

19กลุ่ม method "Change Array by Copy" ของ ES2023 เช่น toSorted() และ toReversed() มีลักษณะอย่างไร?

สไลด์ระบุว่าเป็น additional array methods that make change to an array by returning a new copy ได้แก่ toReversed(), toSorted(), toSpliced() และ with()

20ถ้า A = new Set([1, 2, 3]) และ B = new Set([3, 4, 5]) ผลของ A.intersection(B) ใน ES2025 คืออะไร?

intersection คือสมาชิกที่อยู่ในทั้งสองเซต จึงได้ {3} · union ได้ {1,2,3,4,5} · difference ได้ {1,2} · symmetricDifference ได้ {1,2,4,5}
