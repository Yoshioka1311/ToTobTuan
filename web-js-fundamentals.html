JavaScript คืออะไร

JavaScript ถูกออกแบบมาเพื่อเพิ่มความ interactive ให้หน้า HTML เป็น scripting language แบบ lightweight ที่โดยทั่วไปฝังอยู่ในหน้า HTML โดยตรง

Interpreted language

JavaScript เป็น interpreted language — script ทำงานได้เลยโดยไม่ต้อง compile ล่วงหน้า และมาพร้อม library สำเร็จรูปจำนวนมากที่เรียกว่า API (Application Programming Interfaces)

ความสามารถของ JavaScript

  • ใส่ข้อความ dynamic ลงในหน้า HTML
  • ตอบสนองต่อ event
  • อ่าน/เขียน HTML element
  • validate ข้อมูล
  • ตรวจจับ browser ของผู้เข้าชม
  • สร้าง cookie

ตัวแปร (Variables)

Variable คือกลไกให้โปรแกรมเก็บข้อมูลชั่วคราวแล้วอ้างอิงด้วยชื่อในภายหลัง คำสำคัญ var บ่งบอกว่ากำลังประกาศตัวแปร

= ไม่ใช่เครื่องหมายเท่ากับ

เครื่องหมาย = ใน JS ไม่ใช่เครื่องหมายเท่ากันแบบคณิตศาสตร์ แต่เป็น assignment operator (ตัวดำเนินการกำหนดค่า) — x = x + 1 จึงแปลว่า "เอาค่า x บวก 1 แล้วเก็บกลับลงใน x"

กฎการตั้งชื่อตัวแปร

  1. ต้องขึ้นต้นด้วยตัวอักษร
  2. ประกอบด้วยตัวอักษรและตัวเลขผสมกัน — ห้ามมีช่องว่าง
  3. ห้ามใช้คำสงวน (keyword เช่น var) เป็นชื่อตัวแปร
ชื่อที่ใช้ได้

score · player1 · totalPrice

ชื่อที่ใช้ไม่ได้

1player (ขึ้นต้นด้วยตัวเลข) · total price (มีช่องว่าง) · var (คำสงวน)

var vs let vs const (ES6)

Scopeอัปเดตค่าประกาศซ้ำ (ชื่อเดียวกัน)
varไม่ใช่ block-scoped — scope คือทั้งฟังก์ชันหรือ globalได้ได้ (ตัวแปรใน block ย่อยเขียนทับตัวนอก)
letblock-scopedได้ไม่ได้ ในขอบเขตเดียวกัน
constblock-scopedไม่ได้ไม่ได้

ปัญหาของ var: ตัวแปรชื่อเดียวกันที่ประกาศซ้ำใน code block ย่อยจะไปเขียนทับค่าเดิมของตัวแปรนอก block เพราะ scope ของ var คือทั้งฟังก์ชันหรือ global ไม่ใช่แค่ block นั้น — ส่วน let ใน block ย่อยเป็นตัวแปรคนละตัวกัน

var x = 10;
if (true) {
  var x = 20;   // ประกาศซ้ำใน block ย่อย
}
console.log("var x =", x);   // 20 — ค่าเดิมถูกเขียนทับ

let y = 10;
if (true) {
  let y = 20;   // เป็นตัวแปรของ block นี้เท่านั้น
}
console.log("let y =", y);   // 10 — ค่าเดิมไม่ถูกแตะ

let อัปเดตค่าได้ แต่ประกาศซ้ำในขอบเขตเดียวกันไม่ได้ — รันแล้วจะเกิด SyntaxError ทั้ง script

let a = 1;
a = 2;        // อัปเดตค่าได้
let a = 3;    // ประกาศซ้ำชื่อเดิม → error

const อัปเดตค่าไม่ได้เลยหลังกำหนดค่าเริ่มต้น

const RATE = 7;
console.log(RATE);
RATE = 10;    // เปลี่ยนค่าคงที่ → TypeError

Weakly typed และ typeof

JavaScript เป็นภาษาแบบ "weakly typed" — ตัวแปรหนึ่งตัวเก็บค่าต่างชนิดข้อมูลกันได้ในแต่ละช่วงเวลาของการรันโปรแกรม เช่น ตัวแปรที่เก็บตัวเลขอยู่ถูก assign เป็น string ทีหลังได้ ใช้ typeof ตรวจชนิดข้อมูลของตัวแปร ณ ขณะนั้น

let value = 42;
console.log(value, typeof value);     // number

value = "forty-two";                  // เปลี่ยนเป็น string ได้
console.log(value, typeof value);     // string

value = true;
console.log(value, typeof value);     // boolean

let nothing;
console.log(nothing, typeof nothing); // undefined

Comparison operators

Strict comparison === / !==

เปรียบเทียบทั้งชนิดข้อมูลและค่า

Type-converting == / !=

แปลงชนิดข้อมูลก่อนแล้วจึงเปรียบเทียบ

console.log("1" === 1);   // false — string กับ number คนละชนิด
console.log("1" == 1);    // true  — แปลงชนิดก่อนเปรียบเทียบ
console.log("1" !== 1);   // true
console.log(5 > 3, 5 <= 3);
จุดที่ข้อสอบชอบถาม

"1" === 1 → false (คนละชนิดข้อมูล) แต่ "1" == 1 → true (แปลงชนิดก่อน)

Logical operators

&& (AND), || (OR), ! (NOT) ใช้กับค่า Boolean

const age = 20;
const hasTicket = true;
console.log(age >= 18 && hasTicket);   // true  — จริงทั้งคู่
console.log(age < 18 || hasTicket);    // true  — จริงอย่างน้อยหนึ่ง
console.log(!hasTicket);               // false — กลับค่า

Operator precedence (ลำดับความสำคัญ จากสูงไปต่ำ)

  1. วงเล็บ ()
  2. postfix increment / decrement (x++, x--)
  3. logical NOT / unary (!)
  4. exponentiation (**)
  5. คูณ / หาร / มอดูโล (* / %)
  6. บวก / ลบ (+ -)
  7. comparison (< > <= >=)
  8. equality (== === != !==)
  9. logical AND (&&)
  10. logical OR (||)
  11. assignment (= += …)

ตัวอย่างไล่ลำดับ: let r = 2 + 3 * 4 > 10 && true;

  1. คูณก่อน: 3 * 4 = 12 → 2 + 12 > 10 && true
  2. บวก: 2 + 12 = 14 → 14 > 10 && true
  3. comparison: 14 > 10 = true → true && true
  4. logical AND: true → assignment ทำเป็นขั้นสุดท้าย r = true
let r = 2 + 3 * 4 > 10 && true;
console.log(r);   // true

Decision: if, if-else, if-else-if

โครงสร้างการตัดสินใจเลือกทำคำสั่งตามเงื่อนไข — if-else-if คือการซ้อน if-else หลายชั้นในส่วน else

const score = 72;

if (score >= 50) {
  console.log("ผ่าน");            // if
}

if (score >= 80) {
  console.log("ดีมาก");
} else {
  console.log("ยังไม่ถึง 80");     // if-else
}

if (score >= 80) {
  console.log("A");
} else if (score >= 70) {
  console.log("B");               // if-else-if: เงื่อนไขแรกที่จริงถูกเลือก
} else {
  console.log("C");
}

Ternary operator

condition ? expr1 : expr2

เป็นทางลัดของ if-else — ถ้า condition จริงได้ expr1 ถ้าเท็จได้ expr2

const age = 16;

console.log(status);   // minor

switch

switch จับคู่ค่าของนิพจน์กับ case แล้วรันโค้ดของ case นั้น

Fall through

ถ้า case ไม่มี break โค้ดจะทำงานต่อเนื่องไปยัง case ถัดไป (fall through) จนกว่าจะเจอ break

const fruit = "apple";
switch (fruit) {
  case "apple":
    console.log("apple");
    // ไม่มี break → fall through
  case "banana":
    console.log("banana (ทำงานต่อเพราะ case ก่อนหน้าไม่มี break)");
    break;
  case "cherry":
    console.log("cherry (ไม่ถูกรัน เพราะเจอ break ก่อน)");
    break;
  default:
    console.log("unknown");
}

Repetition: while, do-while, for

หลักการเขียนลูป

ต้องมั่นใจว่าเงื่อนไขของลูปเป็นจริงก่อนรอบแรก และโค้ดในลูปต้องเปลี่ยนแปลงเงื่อนไขเพื่อให้ลูปจบได้ — ป้องกัน infinite loop

ลูปลักษณะ
whileทำซ้ำจนกว่าเงื่อนไขเป็นเท็จ — อาจไม่ทำงานเลยถ้าเงื่อนไขเป็นเท็จตั้งแต่แรก
do-whileทำงานอย่างน้อย 1 ครั้งเสมอก่อนตรวจเงื่อนไข
forfor ([initialization]; [condition]; [final-expression]) { statement }
 
let n = 10;
while (n < 5) {
  console.log("while รอบนี้ไม่เกิด");   // เงื่อนไขเท็จตั้งแต่แรก
}

do {
  console.log("do-while ทำ 1 ครั้ง แม้เงื่อนไขเท็จ");
} while (n < 5);

for (let i = 1; i <= 3; i++) {
  console.log("for รอบที่", i);
}

break และ continue

break

หยุดการทำงานของ loop / switch / label ปัจจุบันทันที

continue

ข้ามคำสั่งที่เหลือในรอบปัจจุบัน แล้วไปเริ่มรอบถัดไปทันที

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;   // ข้ามเลขคู่
  if (i > 7) break;            // เจอเลขเกิน 7 → หยุดลูป
  console.log(i);              // 1 3 5 7
}

Label และ Nesting

Label ใช้ระบุชื่อ code block เพื่ออ้างอิงร่วมกับ break / continue ได้ มีประโยชน์เมื่อมี loop ซ้อนกันหลายชั้น — และโครงสร้างควบคุมซ้อนกัน (nesting) ได้ไม่จำกัดชั้น

outer: for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    if (i === 2 && j === 2) break outer;   // หยุดลูปนอกทั้งหมด
    console.log(i, j);
  }
}

Counter-controlled vs Sentinel-controlled loop

Counter-controlled

ลูปที่ควบคุมด้วยตัวนับที่อัปเดตทุกรอบจนกว่าจะถึงค่าที่กำหนด (มักใช้กับ for / while)

Sentinel-controlled

ลูปที่จบเมื่อพบค่า sentinel — ใช้เมื่อคาดเดาจำนวนรอบล่วงหน้าไม่ได้ (มักใช้กับ while)

// counter-controlled: รู้จำนวนรอบ (5 รอบ)
let sum = 0;
for (let i = 1; i <= 5; i++) sum += i;
console.log("sum 1..5 =", sum);       // 15

// sentinel-controlled: อ่านไปจนเจอค่า -1
const inputs = [8, 3, 5, -1, 9];
let k = 0;
let total = 0;
while (inputs[k] !== -1) {
  total += inputs[k];
  k++;
}
console.log("total ก่อนเจอ -1 =", total);  // 16

การวนซ้ำกับ Array และ Object

Array

for (var i = 0; i < arr.length; i++) เข้าถึงสมาชิกทีละตัวด้วย arr[i]

User-defined object

for (var prop in obj) { ... } วนเข้าถึงชื่อ property ทั้งหมดของ object

01JavaScript เป็นภาษาประเภทใด?

JS เป็น scripting language แบบ lightweight และเป็น interpreted language — script ทำงานได้เลยโดยไม่ต้อง compile

02การแทรก JavaScript ในไฟล์ HTML โดยตรงใช้ tag ใด?

เขียนใน <script>...</script> วางไว้ใน <head> หรือ <body> ก็ได้

03การเชื่อมไฟล์ JS ภายนอกเข้ากับ HTML ใช้วิธีใด?

ใช้ attribute src ของ <script> · ส่วนไฟล์ .js เองไม่ต้องมี tag <script> ครอบ

04ตัวแปรที่ประกาศด้วย var ใน block ย่อยที่ซ้อนอยู่ข้างในจะมีผลอย่างไร?

scope ของ var คือทั้งฟังก์ชันหรือ global ไม่ใช่แค่ block → การประกาศซ้ำใน block ย่อยเขียนทับค่าตัวนอก

05let ต่างจาก var อย่างไรในเรื่อง scope?

let เป็น block-scoped (อัปเดตค่าได้ แต่ประกาศซ้ำในขอบเขตเดียวกันไม่ได้) ส่วน var ผูกกับฟังก์ชันหรือ global

06const ต่างจาก let อย่างไร?

const ใช้กับค่าคงที่ — อัปเดตค่าหรือประกาศซ้ำไม่ได้ ขณะที่ let อัปเดตค่าได้

07JavaScript มี data type พื้นฐานกี่ประเภท?

6 ประเภทตามที่เรียน: Boolean, Number, String, Null, Undefined และ Object

08ตัวแปรที่ถูกประกาศแต่ยังไม่ได้กำหนดค่าจะมีค่าเป็นชนิดข้อมูลใด?

ตัวแปรที่ประกาศแต่ยังไม่กำหนดค่าจะเป็น undefined อัตโนมัติ · null คือการไม่มีค่าโดยตั้งใจ

09JavaScript เป็นภาษาแบบ "weakly typed" หมายความว่าอย่างไร?

ตัวแปรที่เก็บตัวเลขอยู่ถูก assign เป็น string ทีหลังได้ · ตรวจชนิดปัจจุบันด้วย typeof

10เครื่องหมาย === ต่างจาก == อย่างไร?

=== / !== คือ strict comparison · == / != คือ type-converting comparison

11"1" === 1 จะได้ผลลัพธ์เป็นอะไร?

string "1" กับ number 1 คนละชนิดข้อมูล strict comparison จึงได้ false

12"1" == 1 จะได้ผลลัพธ์เป็นอะไร?

== แปลงชนิดข้อมูลก่อนเปรียบเทียบ ค่าจึงเท่ากัน ได้ true

135 % 3 (remainder operator) มีค่าเท่าใด?

% คือหารเอาเศษ: 5 หาร 3 ได้ 1 เศษ 2

14ลำดับความสำคัญของ operator ข้อใดถูกต้อง (จากสูงไปต่ำ)?

ลำดับ: () → postfix → NOT/unary → ** → * / % → + - → comparison → equality → && → || → assignment

15Ternary operator (condition ? expr1 : expr2) ใช้แทนโครงสร้างใด?

ternary operator เป็นทางลัดของ if-else

16switch statement ถ้าไม่มี break; ในแต่ละ case จะเกิดอะไรขึ้น?

ไม่มี break → fall through ไปทำ case ถัดไปต่อจนกว่าจะเจอ break

17while loop กับ do-while loop ต่างกันอย่างไร?

do-while ทำก่อนแล้วค่อยตรวจเงื่อนไข จึงทำอย่างน้อย 1 ครั้ง · while ตรวจก่อน ถ้าเท็จตั้งแต่แรกก็ไม่ทำเลย

18คำสั่ง break ในลูปมีผลอย่างไร?

break หยุด loop / switch / label ปัจจุบันทันที · ข้อ A คือ continue

19คำสั่ง continue ในลูปมีผลอย่างไร?

continue ข้ามคำสั่งที่เหลือของรอบนี้แล้วไปรอบถัดไป · ข้อ A คือ break

20for (var prop in someObject) { ... } ใช้ทำอะไร?

for...in วนผ่านชื่อ property ของ user-defined object · array ใช้ for (var i = 0; i < arr.length; i++)
