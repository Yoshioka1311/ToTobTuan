# โต๊ะทบทวน

เว็บอ่านสอบภาษาไทยแบบ static เปิด `index.html` ได้ทันที ไม่ต้อง build ไม่มีบัญชี ระบบหลังบ้าน หรือ CDN ใช้ฟอนต์ในเครื่อง

## วิชา

- **ITDS211 · Computer Architecture** เอกสาร 8 บท รวม 510 หน้า มีสรุป เนื้อหาอธิบาย และข้อสอบตัวเลือกที่เขียนใหม่ ครอบคลุมพื้นฐานระบบ, CPU, RISC-V, memory/cache, I/O, storage, pipeline และ parallel processors
- **ITDS241 · JavaScript** บทเรียนเดิม 17 หัวข้อ ข้อสอบ 153 ข้อ แยก Part 1 / Part 2 / ECMAScript พร้อม cheatsheet 12 หมวด ข้อเขียนเดิม 51 ข้อเปลี่ยนเป็นตัวเลือกโดยรักษารหัสข้อเดิม

หน้าแรกเลือกวิชา สรุปแสดงประเด็นหลักและพับคำอธิบายไว้ เปิดแท็บ “เนื้อหา” เพื่ออ่านทั้งหมด หรือเปิด PDF ต้นฉบับ ทุกแบบฝึกหัดมี 4 ตัวเลือกและคำตอบที่ถูกต้องเพียงข้อเดียว ไม่มีช่องเขียนตอบหรือพื้นที่แก้โค้ด

## การฝึก

- **ฝึกทีละข้อ** รอบละ 3 หรือ 5 ข้อ เลือกบทและหัวข้อได้ ตรวจหลังเลือกคำตอบ ไม่มีตัวจับเวลา พักแล้วกลับมาทำต่อได้ แม้เปิดวิชาอื่นระหว่างทาง
- **ข้อสอบรวม** ทำทั้งบทหรือทุกบทในวิชาเดียวกันในหน้าเดียว มีสารบัญและตรวจข้อที่ตอบแล้วพร้อมกัน ล้างคำตอบเฉพาะข้อสอบที่เปิดได้โดยยืนยันก่อน
- **คำถามตัวใหญ่** เริ่มที่ 34px เลือก 28 / 34 / 42 / 50px ได้ ขนาดบันทึกไว้ในเครื่อง ตัวเลือกอ่านได้บนมือถือและใช้คีย์บอร์ดเลือกได้
- **ทบทวน** ข้อที่ถึงกำหนดมาก่อน ตามด้วยข้อที่เคยตอบผิดและข้อใหม่ ตอบผิด ข้าม หรือใช้คำใบ้จะนัดทวนใน 10 นาที ตอบถูกเองเว้น 1 / 3 / 7 วันตามรอบ ฝึกซ้ำก่อนกำหนดได้โดยไม่เพิ่มขั้น ผลฝึกแยกจากคะแนนข้อสอบ

ช่วงเวลาทวนเป็นค่าเริ่มต้นของเว็บ ไม่ใช่ตารางที่ผ่านการทดสอบเฉพาะบุคคล ไม่มีการแจ้งเตือนเบื้องหลัง เว็บแสดงรายการเมื่อเปิดใช้ โจทย์เป็นแบบฝึกใหม่ตามหลักในเอกสาร ไม่ใช่การคาดการณ์ข้อสอบจริง

ใช้ Ctrl+K ค้นหาเฉพาะวิชาที่เปิดอยู่ มีโหมดกลางคืน บุ๊กมาร์ก และเครื่องหมายอ่านแล้ว

## เอกสารและความถูกต้อง

เลขอ้างอิงเป็น **หน้า PDF** ซึ่งอาจต่างจากเลขสไลด์หรือเลขหนังสือ สรุปเรียบเรียงใหม่ ไม่ใช่การถอดข้อความทุกบรรทัด สไลด์ที่มีข้อมูลขัดกันมีคำอธิบายกำกับ เช่น MARIE SKIPCOND, โค้ด RISC-V บางตัวอย่าง, เงื่อนไข forwarding และการคำนวณ pipeline/cache ไม่ใช้ตัวเลขในสไลด์ที่ผิดมาเป็นเฉลย

ตารางอุปกรณ์และตัวอย่างฮาร์ดแวร์เก่าอธิบายตามบริบทของเอกสาร ไม่ใช้เป็นข้อมูลสเปกปัจจุบัน ตัวอย่าง JavaScript รุ่นใหม่อาจยังไม่พร้อมใน browser เก่า

PDF เต็ม 12 ไฟล์เก็บใน `materials/` เฉพาะเครื่อง และถูก ignore ใน Git เพื่อไม่เผยแพร่ต้นฉบับอัตโนมัติ หากย้ายเว็บให้คัดลอกโฟลเดอร์นี้ด้วย สำเนาที่ clone จาก GitHub ต้องนำ PDF ของตนเองมาใส่ก่อนเปิดต้นฉบับ:

- `materials/lecture06.pdf`, `lecture07.pdf`, `ecmascript.pdf`, `cheatsheet.pdf`
- `materials/itds211/chapter01.pdf` ถึง `chapter08.pdf` โดยไฟล์ Chapter03_RiscV ต้นฉบับใช้ชื่อ `chapter03.pdf` ในเว็บ

สรุป Markdown อยู่ใน `summaries/` และ `summaries/itds211/` ดาวน์โหลดจากหน้าเอกสารได้ PDF เปิดด้วยตัวอ่านของ browser ในแท็บใหม่

## บันทึก

คำตอบ การอ่าน บุ๊กมาร์ก รอบฝึก และวันทวนเก็บใน localStorage ของ browser/origin นี้ เปลี่ยน browser หรือวิธีเปิดไฟล์อาจเห็นบันทึกคนละชุด หาก storage ถูกบล็อกยังใช้งานได้ แต่ข้อมูลจะอยู่เฉพาะรอบนั้น ปุ่ม “สำรองบันทึก” ดาวน์โหลด JSON ได้

ใช้ storage key เดิม `totobtuan.study.v2` คะแนนข้อเลือกตอบเดิมเก็บไว้ คำตอบจากข้อเขียนที่แปลงเป็นตัวเลือกย้ายไป `legacyWrittenAnswers` และผลทวนเดิมของข้อเหล่านี้ย้ายไป `legacyReview` เพื่อไม่ให้ถูกนับเป็นคะแนนอัตโนมัติ โน้ตและโค้ดเก่ายังเก็บในข้อมูลสำรอง แม้หน้าเว็บใหม่ไม่มีพื้นที่เขียน รอบฝึกจากระบบเขียนตอบเก่าเก็บเป็น `legacyTraining` ส่วนรอบตัวเลือกใหม่แยกตามวิชา

## โครงสร้าง

- `assets/js/content.js`, `questions.js`, `reference.js` เนื้อหา JavaScript เดิม
- `assets/js/javascript-choices.js` ตัวเลือกทดแทนข้อเขียนเดิม 51 ข้อและรายการรหัสสำหรับย้ายข้อมูล
- `assets/js/architecture-a.js`, `architecture-b.js` เนื้อหาและโจทย์ ITDS211 ทั้ง 8 บท
- `assets/js/catalog.js` จัดวิชา บท และคำถามเป็นข้อมูลร่วม
- `assets/js/desk.js`, `assets/css/desk.css` หน้าจอ การนำทาง การตรวจข้อสอบ และการเก็บบันทึก
- `assets/js/study-memory.js` เลือกข้อและกำหนดวันทวน
- `tools/export-notes.cjs`, `tools/export-architecture.cjs` สร้างสรุป Markdown จากเนื้อหาที่เรียบเรียงแล้ว

## ตรวจการทำงาน

รัน `node tools/check.cjs` เพื่อรันชุดตรวจทั้งหมด ตรวจเนื้อหา ตัวเลือก เลขหน้า บันทึกเก่า การสลับวิชา การฝึก การพักทำต่อ และหน้าจอมือถือ

Browser checks ใช้ Playwright และ Edge ที่ติดตั้งอยู่แล้ว กำหนด `STUDY_PLAYWRIGHT` เป็นพาธแพ็กเกจ และ `STUDY_BROWSER` เป็นพาธ browser executable ได้หากไม่ได้ใช้ bundled runtime ไม่เพิ่ม dependency ให้เว็บ

แยกรันได้ด้วย `node --test tests/content.test.cjs tests/study-memory.test.cjs tests/subjects.test.cjs` หรือ `node tests/browser.test.cjs`, `node tests/exams.test.cjs`, `node tests/coach.test.cjs`, `node tests/desk.test.cjs`, `node tests/migration.test.cjs`
