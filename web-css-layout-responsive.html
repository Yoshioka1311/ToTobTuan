เทคนิคจัด Layout หน้าเว็บ 5 วิธี

#เทคนิคลักษณะ
1HTML tablesไม่แนะนำให้ใช้จัด layout เพราะ <table> ถูกออกแบบมาสำหรับแสดงข้อมูลตาราง
2CSS float propertyจัด layout ด้วย float และ clear
3CSS flexboxโครงสร้าง layout แบบยืดหยุ่น responsive ได้ดีบนอุปกรณ์หลายขนาด
4CSS frameworkวิธีที่เร็วในการสร้าง layout เช่น Bootstrap
5CSS gridระบบ layout แบบตาราง ใช้ row และ column พร้อมกัน
CSS Grid เทียบ Flexbox

CSS Grid ใช้ระบบ row และ column พร้อมกัน (สองมิติ) ส่วน Flexbox เน้นจัดเรียงในมิติเดียว (แถวหรือคอลัมน์ตาม flex-direction)

Layout ด้วย CSS Float

จัด layout โดยใช้ tag แบบ container เช่น header, nav, footer, article, section, div ร่วมกับ float property ตัวอย่างโครงสร้าง CSS สมบูรณ์จากสไลด์สำหรับ 3-column layout (layout 3 คอลัมน์มักใช้กับ Desktop Browser):

* { font-family: sans-serif; }
header, footer { background-color: #f1f1f1; padding: 3px; text-align: center; }
nav { background-color: darkblue; }
nav a { float: right; display: block; color: #f2f2f2;
        text-align: center; padding: 14px 16px; text-decoration: none; }
.container { background-color: gainsboro; }
.column { float: left; width: 33.33%; background-color: lightskyblue; }
.row::after { content: ""; display: table; clear: both; }
กฎทำหน้าที่อะไรใน layout
header, footergrouping selector — พื้นสีเทาอ่อน padding 3px จัดข้อความกึ่งกลาง
nav aลิงก์ในเมนู float: right เรียงชิดขวา · display: block · text-decoration: none ลบเส้นใต้
.columnfloat: left + width: 33.33% → 3 คอลัมน์เรียงกันพอดีหนึ่งแถว
.row::afterclear float หลังแถวของคอลัมน์ (อธิบายด้านล่าง)
 
<style>
  * { font-family: sans-serif; }
  header, footer { background-color: #f1f1f1; padding: 3px; text-align: center; }
  nav { background-color: darkblue; }
  nav a { float: right; display: block; color: #f2f2f2;
          text-align: center; padding: 14px 16px; text-decoration: none; }
  .container { background-color: gainsboro; }
  .column { float: left; width: 33.33%; background-color: lightskyblue; }
  .row::after { content: ""; display: table; clear: both; }
</style>

<nav><a href="#">Contact</a><a href="#">News</a><a href="#">Home</a></nav>
<div class="nav-clear" style="clear: both"></div>

    <div class="column"><p>Column 3</p></div>
  </div>
</div>

ในตัวอย่างที่ลองได้ มี <div style="clear: both"> คั่นหลัง nav เพื่อให้ลิงก์ที่ float อยู่ไม่ไหลทับส่วนถัดไปเช่นกัน

Pseudo-element ::after กับการ clear float

นิยาม

::after เป็น pseudo-element ตัวหนึ่งที่ใช้จัดสไตล์เฉพาะบางส่วนของ element — ในตัวอย่างนี้ใช้เพื่อ "clear float" หลัง container เพื่อไม่ให้ element ที่ตามมาไหลผิดตำแหน่ง

ลองดูผลเมื่อไม่มี .row::after: คอลัมน์ที่ float อยู่ไม่ถูก clear ทำให้ footer ไหลขึ้นไปอยู่ข้างคอลัมน์และพื้นหลังของ container หายไป

<style>
  * { font-family: sans-serif; }
  .container { background-color: gainsboro; }
  .column { float: left; width: 33.33%; background-color: lightskyblue; }
  footer { background-color: #f1f1f1; text-align: center; }
  /* ไม่มี .row::after */
</style>
<div class="container">
  <div class="row">
    <div class="column"><p>Column 1</p></div>
    <div class="column"><p>Column 2 ยาวกว่า<br>สองบรรทัด</p></div>
  </div>
</div>
<footer><p>Footer ไหลผิดตำแหน่ง</p></footer>

Flexbox คืออะไร Container properties ลองเล่น flexbox Flexbox vs Float

Flexbox (Flexible Box) คืออะไร

Flexbox module ช่วยจัดวาง จัดตำแหน่ง และกระจายพื้นที่ระหว่าง item ใน container ที่มีขนาดไม่แน่นอนได้อย่างมีประสิทธิภาพ และออกแบบ layout แบบ responsive ได้โดยไม่ต้องพึ่ง float หรือ positioning

ข้อควรจำ

display: flex; กำหนดที่ element แม่ (flex container) ไม่ใช่ที่ element ลูก

Property หลักของ flex container

Propertyทำอะไรค่าที่เป็นไปได้
displayเปิดใช้งาน flex layoutflex
flex-directionทิศทางการเรียง itemrow | row-reverse | column | column-reverse
flex-wrapให้ item ตัดขึ้นบรรทัดใหม่เมื่อพื้นที่ไม่พอnowrap | wrap | wrap-reverse
justify-contentกระจายพื้นที่ว่างระหว่าง item ตามแนวหลักflex-start | flex-end | center | space-between | space-around | space-evenly
align-itemsจัดตำแหน่ง itemflex-start | flex-end | center

ตัวอย่างที่ใช้ property ครบชุดตามสไลด์:

<style>
  .container {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: space-evenly;
    background-color: gainsboro;
  }
  .container div { width: 120px; margin: 8px; padding: 16px 0;
                   text-align: center; background-color: lightskyblue; }
</style>
<div class="container">
  <div>1</div><div>2</div><div>3</div><div>4</div><div>5</div>
</div>

Flexbox เทียบกับ Float layout

Float layout

ต้องใช้ float + width ของแต่ละคอลัมน์ และต้องมี .row::after เพื่อ clear float หลัง container

Flexbox

ใส่ display: flex ที่ container แล้วคุมทิศทาง/การกระจายพื้นที่ด้วย property ของ container — ไม่ต้องใช้ ::after เพื่อ clear float อีกต่อไป โค้ดสะอาดและยืดหยุ่นกว่า

3-column layout เดียวกับการ์ด 01 แต่เขียนด้วย flexbox:

<style>
  * { font-family: sans-serif; }
  .row { display: flex; background-color: gainsboro; }
  .column { width: 33.33%; background-color: lightskyblue; }
</style>
<div class="row">
  <div class="column"><p>Column 1</p></div>
  <div class="column"><p>Column 2</p></div>
  <div class="column"><p>Column 3</p></div>
</div>

RWD & Mobile First Media Query ลองเล่น media query Viewport meta tag

Responsive Web Design (RWD)

นิยาม (จาก Wikipedia)

แนวทางการออกแบบเว็บที่ทำให้หน้าเว็บแสดงผลได้ดีบนอุปกรณ์และขนาดหน้าจอที่หลากหลาย

RWD ใช้เพียง HTML และ CSS (โดยเฉพาะ Media Query) ในการปรับเนื้อหาตามขนาดหน้าจอหรืออุปกรณ์

Mobile First

ออกแบบสำหรับมือถือก่อน แล้วค่อยขยายไปรองรับหน้าจอที่ใหญ่ขึ้น

แนวทางดั้งเดิม

เริ่มออกแบบจาก desktop ก่อน (ตรงข้ามกับ Mobile First)

ทดสอบก่อนเผยแพร่

ควรทดสอบเว็บด้วย Developer Tools ของ Browser ในโหมด responsive เพื่อตรวจสอบว่า layout ปรับตัวถูกต้องตามขนาดหน้าจอ/อุปกรณ์ต่างๆ ก่อนเผยแพร่จริง

CSS Media Query

media query ใช้ตรวจสอบเงื่อนไขต่างๆ แล้วใช้ CSS ชุดนั้นเฉพาะเมื่อเงื่อนไขเป็นจริง เช่น

  • ความกว้าง/สูงของ viewport
  • ความกว้าง/สูงของอุปกรณ์
  • orientation (แนวนอน/แนวตั้ง)
  • ความละเอียดหน้าจอ
@media mediatype and (expressions) { CSS Block; }

ตัวอย่างจากสไลด์:

body { background-color: black; } /* ค่าเริ่มต้น */

@media screen and (max-width: 768px) {
    body { background-color: lightgreen; } /* จอเล็กกว่า 768px */
}

@media screen and (min-width: 1000px) {
    body { background-color: red; } /* จอใหญ่กว่า 1000px */
}
ความกว้างหน้าจอเงื่อนไขที่เป็นจริงสีพื้นหลัง
≤ 768pxmax-width: 768pxlightgreen
769px – 999pxไม่มี media query ใดเป็นจริง → ใช้ค่าเริ่มต้นblack
≥ 1000pxmin-width: 1000pxred
อ่าน max / min ให้ถูก

max-width: 768px = ใช้เมื่อหน้าจอกว้างน้อยกว่าหรือเท่ากับ 768px · min-width: 1000px = ใช้เมื่อหน้าจอกว้างมากกว่าหรือเท่ากับ 1000px

ลองเล่น: ปรับความกว้าง viewport แล้วดู media query ทำงาน

iframe ด้านล่างใช้ CSS ตัวอย่างข้างบนจริง — เลื่อนแถบเพื่อเปลี่ยนความกว้างของ viewport

Viewport และ <meta> tag

HTML5 เปิดให้นักออกแบบควบคุม viewport (พื้นที่ที่ผู้ใช้มองเห็นได้ของหน้าเว็บ) ผ่าน <meta> tag — สำหรับ RWD ต้องใส่คำสั่งนี้ใน <head> เสมอ

<meta name="viewport" content="width=device-width, initial-scale=1.0" />
width=device-width
ทำให้หน้าเว็บมีความกว้างตามอุปกรณ์จริงเสมอ
initial-scale=1.0
กำหนดระดับการซูมเริ่มต้นตอนโหลดหน้า

CSS Framework ขั้นตอนสร้างหน้าเว็บ .container vs .container-fluid Grid 12 คอลัมน์

CSS Framework และ Bootstrap

CSS Framework ช่วยให้นักพัฒนาเว็บเริ่มต้นออกแบบเว็บไซต์ได้เร็วขึ้นด้วยโครงสร้างพื้นฐานสำเร็จรูป ข้อดีคือ เร็วกว่า · มี UI component สำเร็จรูป · ประสิทธิภาพดี ตัวอย่าง framework อื่นๆ: Tailwind CSS, Bulma, UIkit

Bootstrap

front-end framework ฟรีสำหรับพัฒนาเว็บได้เร็วและง่ายขึ้น รองรับ responsive design และมีแนวคิด mobile-first เป็นแกนหลักของ framework

ขั้นตอนสร้างหน้าเว็บด้วย Bootstrap

  1. สร้าง HTML5 document template พร้อม <meta viewport> สำหรับ mobile-first
  2. เชื่อมไฟล์ Bootstrap CSS และ JS ใน <head> ผ่าน CDN (ลิงก์จาก jsdelivr.net)
  3. จัด layout ด้วยระบบ Grid: ใช้ .container หรือ .container-fluid ครอบเนื้อหาเสมอ แล้วแบ่งเป็น row → column → content ตามลำดับชั้น
  4. เพิ่ม class/component ต่างๆ เช่น Typography, Card, Navbar, Form, Modal และ utility class เช่น Text, Spacing, Color
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <!-- 2. เชื่อม Bootstrap CSS และ JS ผ่าน CDN (jsdelivr.net) -->
  <link rel="stylesheet" href="(ลิงก์ Bootstrap CSS จาก jsdelivr.net)" />
  <script src="(ลิงก์ Bootstrap JS จาก jsdelivr.net)"></script>
</head>
<body>
  <!-- 3. container → row → column → content -->
  <div class="container">
    <div class="row">
      <div class="col-sm-6">ครึ่งซ้าย</div>
      <div class="col-sm-6">ครึ่งขวา</div>
    </div>
  </div>
</body>
</html>

ค่า href / src ในตัวอย่างเป็นตำแหน่งที่ต้องใส่ลิงก์ CDN จริงจากสไลด์

.container

ระบบ Grid ของ Bootstrap

Grid ของ Bootstrap สร้างด้วย flexbox และรองรับได้สูงสุด 12 คอลัมน์ต่อแถว — ผลรวมของ col ในแต่ละแถวควรรวมกันได้ไม่เกิน 12

HTML tables ไม่แนะนำให้ใช้จัด layout เพราะ <table> ถูกออกแบบมาสำหรับแสดงข้อมูลตาราง

03Flexbox ช่วยแก้ปัญหาอะไรเมื่อเทียบกับการใช้ float จัด layout?

Flexbox จัดวาง จัดตำแหน่ง และกระจายพื้นที่ระหว่าง item ใน container ที่ขนาดไม่แน่นอนได้ โดยไม่ต้องพึ่ง float หรือ positioning

04property display: flex; ต้องกำหนดที่ element ใด?

กำหนดที่ container (parent) แล้ว element ลูกโดยตรงทั้งหมดจะกลายเป็น flex items

05property flex-direction: column; มีผลอย่างไร?

flex-direction กำหนดทิศทางการเรียง item · column = เรียงแนวตั้งบนลงล่าง ส่วน row = แนวนอน

06Responsive Web Design (RWD) ใช้เทคโนโลยีหลักใดในการปรับเนื้อหาตามขนาดหน้าจอ?

RWD ใช้เพียง HTML และ CSS (โดยเฉพาะ Media Query) ปรับเนื้อหาตามขนาดหน้าจอหรืออุปกรณ์

07แนวคิด "Mobile First" หมายถึงอะไร?

Mobile First = ออกแบบสำหรับมือถือก่อนแล้วค่อยขยาย (ตรงข้ามกับแนวทางดั้งเดิมที่เริ่มจาก desktop)

08@media screen and (max-width: 768px) { ... } มีความหมายว่าอย่างไร?

max-width: 768px = ความกว้างสูงสุด 768px → ใช้เมื่อหน้าจอกว้างไม่เกิน 768px (ตัวอย่างในสไลด์เปลี่ยนพื้นหลังเป็น lightgreen)

09<meta name="viewport" content="width=device-width, initial-scale=1.0" /> มีความสำคัญอย่างไรต่อ RWD?

width=device-width → กว้างตามอุปกรณ์จริง · initial-scale=1.0 → ระดับซูมเริ่มต้นตอนโหลดหน้า

10Bootstrap คืออะไร?

Bootstrap เป็น front-end framework ฟรี รองรับ responsive design และมี mobile-first เป็นแกนหลัก

11Bootstrap กำหนดให้หน้าเว็บต้องมี containing element ประเภทใด?

ใช้ .container หรือ .container-fluid ครอบเนื้อหาเสมอ

12ระบบ Grid ของ Bootstrap แบ่งความกว้างหน้าจอออกเป็นกี่คอลัมน์สูงสุดต่อแถว?

Grid ของ Bootstrap (สร้างด้วย flexbox) รองรับได้สูงสุด 12 คอลัมน์ต่อแถว

13ในระบบ Grid ของ Bootstrap โครงสร้างลำดับชั้นที่ถูกต้องคือข้อใด?

container ครอบ row และ row แบ่งเป็น column แล้วจึงใส่ content

14.container ต่างจาก .container-fluid อย่างไร?

.container มี max-width ที่แต่ละ breakpoint · .container-fluid กว้าง 100% ทุก breakpoint

15class="col-sm-6" ใน Bootstrap หมายถึงอะไร?

col-sm-6 = 6 จาก 12 หน่วยของแถว เมื่อหน้าจอตั้งแต่ breakpoint sm (576px) ขึ้นไป

16เทคนิคจัด layout แบบใดที่ต้องใช้ pseudo-element ::after เพื่อ "clear float" หลัง container?

Float layout ใช้ .row::after { content: ""; display: table; clear: both; } เพื่อ clear float

17ข้อดีของ Flexbox เมื่อเทียบกับ Float ในการจัด layout คือข้อใด?

ข้อดีสำคัญของ flexbox คือไม่ต้องใช้ ::after เพื่อ clear float อีกต่อไป โค้ดสะอาดและยืดหยุ่นกว่า

18Layout แบบ 3-column มักใช้กับอุปกรณ์ประเภทใดตามที่เรียน?

3-column layout มักใช้กับ Desktop Browser ที่มีพื้นที่หน้าจอกว้าง

19เหตุใดจึงควรทดสอบเว็บด้วย Developer Tools ของ Browser ในโหมด responsive?

โหมด responsive ของ DevTools ใช้ตรวจว่า layout ปรับตามขนาดหน้าจอ/อุปกรณ์ได้ถูกต้องก่อนเผยแพร่

20CSS Grid ต่างจาก Flexbox โดยพื้นฐานอย่างไร?

CSS grid = ระบบ layout แบบตาราง row และ column พร้อมกัน (สองมิติ) · Flexbox เรียงในมิติเดียว
